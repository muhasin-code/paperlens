## Step 4 — Install and Verify Ollama

### Actions — install

Follow [ollama.com/download/linux](https://ollama.com/download/linux) or:

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

Ensure the service is running:

```bash
sudo systemctl enable ollama
sudo systemctl start ollama
sudo systemctl status ollama --no-pager
```

### Actions — pull model

Choose **one** primary chat model (start with the smaller option if RAM is tight):

```bash
# Recommended default (blueprint)
ollama pull phi4-mini
```

### Actions — smoke test

```bash
ollama list

time ollama run phi4-mini "Reply with exactly: PaperLens OK"
# Note wall-clock time and tokens/sec from output
```

Optional API check (used by FastAPI later):

```bash
curl -s http://localhost:11434/api/tags | head
curl -s http://localhost:11434/api/generate -d '{
  "model": "phi4-mini",
  "prompt": "Say hello in one word.",
  "stream": false
}' | python3 -m json.tool | head -20
```

### RAM note (16 GB machine)

With 16 GB RAM, running Ollama + embedding model + reranker concurrently may swap. Record observed RAM during `ollama run`:

```bash
# In another terminal while model runs
free -h
```

If swap usage is high, document plan to use `llama3.2:1b` for dev or serialize model loading — note in `docs/dev-environment.md`.

## Step 6 — Create `.env.example`

Create **`.env.example`** at repo root — the template for all config. Developers copy to `.env` (gitignored). Use placeholders only; never real secrets.

### Required variables

```bash
# --- Application ---
APP_ENV=development
LOG_LEVEL=INFO
API_HOST=0.0.0.0
API_PORT=8000
GRADIO_PORT=7860

# --- Paths ---
DATA_DIR=./data
CHROMA_PERSIST_DIR=./data/chroma
BM25_INDEX_PATH=./data/bm25_index.pkl
PROCESSED_CHUNKS_PATH=./data/processed/chunks.parquet

# --- Ollama ---
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama3.2:3b
# OLLAMA_MODEL=phi4-mini

# --- Embeddings & retrieval ---
EMBEDDING_MODEL=BAAI/bge-large-en-v1.5
RERANKER_MODEL=cross-encoder/ms-marco-MiniLM-L-12-v2
RETRIEVAL_TOP_K=20
RERANK_TOP_K=5
CHUNK_SIZE_TOKENS=600
CHUNK_OVERLAP_TOKENS=100

# --- arXiv ingestion (Phase 1) ---
ARXIV_MAX_RESULTS=500
ARXIV_CATEGORY=cs.LG
# Examples: cs.LG, cs.CL, cs.AI — pick one subfield in Milestone 1.1

# --- Fine-tuned extractor (Phase 3) ---
HF_HUB_MODEL_ID=
# Base: Qwen/Qwen2.5-3B-Instruct; adapter path on Hub after fine-tuning
EXTRACTION_ADAPTER_REPO=
HF_TOKEN=
# Optional — only needed to push/pull private Hub assets

# --- Langfuse (Phase 4) ---
LANGFUSE_PUBLIC_KEY=
LANGFUSE_SECRET_KEY=
LANGFUSE_HOST=http://localhost:3000

# --- Evaluation (Phase 4) ---
RAGAS_FAITHFULNESS_THRESHOLD=0.75
GOLD_DATASET_PATH=./eval/gold_dataset.jsonl

# --- Prompts ---
PROMPTS_DIR=./configs/prompts
PROMPT_VERSION=v1
```

### Actions

```bash
cp .env.example .env
# .env is gitignored — edit locally as needed during development
```
